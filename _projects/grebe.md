### The Challenge
While open source software for using arduino hardware to interface with the Windows volume mixer already exists (notably [deej](https://github.com/omriharel/deej)), it is limited by use of hardware sliders. This project aims to instead use rotary encoders in conjunction with a small screen to allow greater flexibility.
